# 🚨 Центр обращений 112.

**Центр обращений 112** — это система для приёма и обработки обращений граждан через **Telegram‑бота**, **веб‑сайт** и **админ‑панель**.  
Проект создан для того, чтобы сделать взаимодействие граждан с администрацией удобным, быстрым и прозрачным.

---

## 🌍 Возможности

### 👥 Для пользователей
- Отправка обращений через сайт или Telegram‑бот.
- Возможность прикрепить **фото, видео, геолокацию**.
- Автоматическая отправка заявки в базу данных.

### 🧑‍💼 Для администраторов
- Просмотр всех обращений в **админ‑панели**.
- Изменение статуса: _Новая_, _В обработке_, _Завершено_, _Отклонено_.
- Добавление **комментариев** и фильтрация заявок по статусу.

## 🚀 Запуск проекта

1. Клонируйте репозиторий и перейдите в папку `backend`:
   ```bash
   git clone https://github.com/yourusername/center-112.git
   cd center-112/backend
   ```

2. Настройте `.env` файл:
   ```env
   TELEGRAM_TOKEN=ваш_токен_бота
   DATABASE_URL=postgres://postgres:пароль@localhost:5432/telegramm-bot?sslmode=disable
   ADMIN_SECRET=секрет_для_админки
   API_TOKEN=changeme_api_token
   PORT=9098
   ```

3. Выполните миграции:
   ```bash
   psql "postgres://postgres:пароль@localhost:5432/telegramm-bot?sslmode=disable" -f migrations/init.sql
   ```

4. Запустите сервер:
   ```bash
   go run ./cmd
   ```

5. Откройте в браузере:
   - Сайт: [http://localhost:9098/](http://localhost:9098/)
   - Админ‑панель: [http://localhost:9098/admin-panel/](http://localhost:9098/admin/)

6. Доступ к боту:
   - Бот будет доступен по ссылке: https://t.me/dev_helper_112_bot.
